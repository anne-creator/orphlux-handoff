01 / DATASET OVERVIEW

EXPERT-LEVEL TASK DATA

SCOPE & PURPOSE

The training task.

  • LONG-HORIZON ENGINEERING
  • FIVE LANGUAGES
  • BEHAVIOR-LEVEL VERIFICATION

Designed for long-horizon software engineering task solving by frontier coding agents, DeepSWE provides original, contamination-free engineering task data. The dataset covers five programming languages, with tasks created from scratch and independently verified based on software behavior, enabling evaluation of real-world engineering capabilities rather than memorization. It can be used for coding agent training, capability evaluation, and failure-mode research.

03 / DATA PRODUCTION & CONSTRUCTION

METHOD & WORKFLOW

Data production strengths

We have dual-source data acquisition capabilities covering open-source repositories and authorized private repositories, together with expertise in designing original long-horizon tasks across languages and repositories. Our capabilities cover sandboxed trajectory collection, behavior-level test development, and patch-level independent verification, supporting the full workflow from task creation and execution to quality control and scoring.
