# Historical materials by version

[Download historical material archive](https://github.com/anne-creator/orphlux-handoff/releases/download/handoff-2026-11-17/OrphLux-historical-materials-2026-11-17.zip)

The archive preserves dated working folders and version names. [ASSET-INDEX.csv](ASSET-INDEX.csv) maps every included original path to its archive file, size and SHA-256. Exact duplicate content is stored once; all original paths remain listed.

841 indexed media paths, 692 unique files. Materials include early directions, Hero still/video studies, service/dataset/Research artwork, footer studies, brand-guide artwork and later comparison studies. PNG/JPG/WebP are rendered imagery; SVG is editable vector source; MP4/WebM/MOV are video outputs. Historical alternatives are not all selected or approved.

Source images and render previews remain separated by their original version folders. Historical user prompts, generation request logs, chats and account screenshots are excluded. Runtime source is in the two website folders.
